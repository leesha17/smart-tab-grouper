# 🗂️ Smart Tab Grouper Chrome Extension

A productivity-focused Chrome extension built with Plasmo + React + TypeScript.

## Features

* Auto-group tabs by category
* Keyboard shortcuts
* Search open tabs
* Export tab groups
* Browsing statistics dashboard
* Smart study/work grouping

## Categories

* Study
* Dev
* Social
* Shopping
* Video

## Tech Stack

* TypeScript
* React
* Plasmo Framework
* Chrome Extensions API
